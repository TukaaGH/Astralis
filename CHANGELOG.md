# Changelog

## 1.0.4 — 2026-10-28

Added configs: save, load, delete and select a startup profile. Added gun-only autoshoot with menu, modal and freecam checks. Improved manipulation range searches and motion cleanup after respawns.

Fixed setting callbacks, reload ordering, key modes, config rollback, startup selection, textbox input, camera restoration and unload cleanup. Fixed crossbows losing their loaded state while freecam blocked firing.

Updated UI library to v6. Experimental flight/desync is not included.
